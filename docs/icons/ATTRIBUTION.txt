  phone-mobile.svg     1f4f1.svg (MOBILE PHONE)      - the smart state

HOME SCREEN / INSTALLED APP — custom, commissioned for this site
---------------------------------------------------------------
  apple-touch-icon.png       180x180  iOS home screen (iOS ignores the manifest
                                      icons when this is present)
  icon-192.png               192x192  manifest, purpose "any"
  icon-512.png               512x512  manifest, purpose "any"
  icon-512-maskable.png      512x512  manifest, purpose "maskable"

  The photograph is the same caracal image used on the page itself
  (../images/big-floppa.webp). The gradient behind it runs from --accent
  (#ff3ea5) to --ticker-fg (#7df9ff), the two accent colours defined in
  ../style.css - pink for the flip variant, cyan for the smart one.

  All four are fully opaque and full-bleed: iOS does not honour the alpha
  channel on a home screen icon and would flatten transparency to black.
  Re-encoded from the delivered PNGs to a 256-colour palette - 260K down from
  919K, with no visible difference at any size these are drawn at.
